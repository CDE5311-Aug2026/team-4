# 楼下 Downstairs · 金文泰：部署到 Vercel

这个文件夹可以直接部署到 Vercel。游戏本身是静态网页（`public/`）；`api/` 里的三个小函数负责把居民对话转给 DeepSeek，Key 只放在 Vercel 的环境变量里，不会出现在网页代码中。

## 部署步骤（网页上操作）

1. 把这个文件夹放进一个 GitHub 仓库（文件夹里的内容放在仓库根目录）。
2. 打开 vercel.com → **Add New… → Project** → 选这个仓库 → **Import**。
3. **Framework Preset** 选 **Other**；Build Command、Output Directory 保持空白（`vercel.json` 已经写好：直接发布 `public/`）。
4. 展开 **Environment Variables**，添加：
   - Name：`DEEPSEEK_API_KEY`
   - Value：你的 DeepSeek Key
5. 点 **Deploy**。完成后打开给出的网址就能玩。

不想用 GitHub 也可以：装好 Node 后在这个文件夹里运行 `npx vercel`，按提示登录、创建项目；然后在 Vercel 项目的 Settings → Environment Variables 里加上 `DEEPSEEK_API_KEY`，再运行 `npx vercel --prod`。

## 不填 Key 会怎样

游戏照常运行，居民改用离线对白（和本机没连上 DeepSeek 时一样）。之后在 Vercel 里补上 Key，再 **Redeploy** 一次即可生效。

## 注意

- 网站公开后，任何打开网页的人都会用到这把 Key 的额度。建议用一把单独的 Key，并在 DeepSeek 后台只充少量余额。
- 接口只接受来自本站页面的请求，单次请求有大小上限；每句对话大约 5–20 秒，函数最长运行 60 秒。
- 不要把 Key 写进任何文件或提交到仓库（`.gitignore` 已经排除了 `.env` 和 `deepseek-key.txt`）。

## 文件

- `public/`：游戏页面（与本机 `clementi-demo/dist` 相同，2026-11-12 版本）。
- `api/dialogue.js`：居民对话 → DeepSeek。
- `api/ai-status.js`、`api/ai-check.js`：告诉游戏有没有配置 Key、能不能连上。
- `vercel.json`：发布设置。
